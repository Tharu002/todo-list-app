# Todo List App ✅

A simple and elegant todo list web application to manage your daily tasks.

## Features
- ✨ Add new tasks
- ✅ Mark tasks as complete
- 🗑️ Delete tasks
- 💾 Local storage (tasks persist after refresh)
- 📱 Responsive design

## 🚀 Live Demo
**[👉 Click here to try it live!](https://tharu002.github.io/todo-list-app/)**

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)
