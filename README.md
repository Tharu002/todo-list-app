# Todo List App ✅

A simple and elegant todo list web application to manage your daily tasks.

## Features
- ✨ Add new tasks
- ✅ Mark tasks as complete
- 🗑️ Delete tasks
- 💾 Local storage (tasks persist after refresh)
- 📱 Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Use
1. Clone this repository
2. Open `index.html` in your browser
3. Start adding your tasks!
